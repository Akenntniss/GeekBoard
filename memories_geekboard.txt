# Mémoires GeekBoard - Base de Connaissances Projet

## 1. Architecture & Base de Données
- **Système Multi-Database** : Architecture basée sur les sous-domaines.
  - Exemples mdgeek.top :
    - `mkmkmk.mdgeek.top` → `geekboard_mkmkmk`
    - `cannesphones.mdgeek.top` → `geekboard_cannesphones`
  - Exemples servo.tools :
    - `mkmkmk.servo.tools` → `geekboard_mkmkmk` (shop_id: 63)
    - `phonesystem.servo.tools` → `geekboard_phonesystem` (shop_id: 104)
    - `phoneetoile.servo.tools` → `geekboard_phoneetoile` (shop_id: 105)
- **Connexion** : 
  - Utiliser TOUJOURS `getShopDBConnection()` (config/database.php).
  - JAMAIS de connexions hardcodées comme "geekboard_mkmkmk" - toujours respecter l'architecture multi-magasin.
  - `SubdomainDatabaseDetector` détecte la DB via le sous-domaine.
  - `detectShopFromSubdomain()` initialise `shop_id` en session depuis la table `shops` de `geekboard_general`.
  - Les APIs directes doivent appeler `initializeShopSession()` si elles sont appelées directement sans passer par l'initialisation normale de session.
- **Structure** : Base principale `geekboard_general` contient la table `shops` avec mappings sous-domaines → bases de données magasins.
