                         Instructions d'Installation

╔═══════════════════════════════════════════════════════════════════════════════╗
║                      INSTALLATION AUTOMATIQUE (RECOMMANDÉE)                   ║
╚═══════════════════════════════════════════════════════════════════════════════╝

Étape 1 : Ouvrir Terminal (Applications → Utilitaires → Terminal)

Étape 2 : Glisser le fichier "Installer_SERVO.command" dans la fenêtre Terminal

Étape 3 : Appuyer sur Entrée

Étape 4 : Saisir votre mot de passe Mac (les caractères ne s'affichent pas)

Étape 5 : Appuyer sur Entrée

→ L'application sera automatiquement installée et prête à l'emploi !


╔═══════════════════════════════════════════════════════════════════════════════╗
║                           INSTALLATION MANUELLE                               ║
╚═══════════════════════════════════════════════════════════════════════════════╝

Étape 1 : Déplacer le fichier SERVO.app dans le dossier /Applications

Étape 2 : Ouvrir Terminal (Applications → Utilitaires → Terminal)

Étape 3 : Copier-coller cette commande :

    xattr -cr /Applications/SERVO.app

Étape 4 : Appuyer sur Entrée

→ L'application est maintenant prête à être lancée !
